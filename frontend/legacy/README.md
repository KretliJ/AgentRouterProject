# Legacy — Protótipo visual v1 (site estático)

Versão congelada do protótipo em JavaScript (Three.js + SVG), mantida
apenas como **artefato visual de referência** enquanto o núcleo real
(Java + orquestrador Python) é implementado em `../core` e `../orchestrator`.

- Abre direto no navegador via `file://` — zero dependências.
- O motor de simulação aqui (`sim.js`) é uma antecipação da semântica
  do núcleo Java; a fonte da verdade passa a ser o backend.
- Não desenvolver mais este código; correções visuais novas devem ir
  para o frontend do sistema real.
